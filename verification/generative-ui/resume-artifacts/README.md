# Isolated authored artifact acceptance

`run.mjs` restores the committed genuinely authored A compare/calendar/journey trees and B comparison/calendar programs in fresh Chrome contexts. It uses the current real fare API, browser query worker, and native assistant-ui/OpenUI adapters. Chat requests are intercepted only to inspect the next compact snapshot and return a labeled local probe response. No model calls run, and no existing user browser storage is read or changed.

The runner checks 360/800/1280px overflow, visible control names, keyboard selection/action events, focus retention, available synthetic totals, next-snapshot validation, and row-free request/persisted-thread boundaries. Reduced motion is checked from computed animation and transition styles. No axe package is installed; these DOM and keyboard checks do not claim a hands-on screen-reader review or blinded human ratings.

`pre-fix-results.json` retains reproduced native fare-button focus loss. Initial reactive attempts also retain runner locator/keyboard diagnostics in local directories; the old captured B programs use native select controls and include historical text-decoder artifacts. The runner preserves their exact authored source rather than applying a lossy text conversion. Current browser keyboard selection uses native select typeahead after actual query options arrive, because this Mac's headless native select did not change with ArrowDown/Enter.

`restoreRecordedThread(page, {variant, record, expectedSourceVersion, reload})` in `replay-artifact.mjs` is for caller-owned isolated contexts. It rejects copied rows, incompatible records, changed resource IDs, or changed fixture generations before saving. A custom reload callback permits frames. It never clears a store or changes a user's session. The caller must isolate each review item or use its own dedicated origin.

Run against the verified preview:

```sh
OMIO_DEMO_URL=http://127.0.0.1:5194 node verification/generative-ui/resume-artifacts/run.mjs
```

Optional `OMIO_ARTIFACT_VARIANTS`, `OMIO_ARTIFACT_INDEX`, `OMIO_ARTIFACT_WIDTHS`, and `OMIO_ARTIFACT_OUTPUT` narrow diagnostics and preserve earlier results. `helper-proof/results.json` is a current real-data native restore proof, recorded on 2026-10-03 with zero model calls. It is not a study cell or new authorship evidence.
