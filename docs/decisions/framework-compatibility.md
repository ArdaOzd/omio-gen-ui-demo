# Resolved generative UI framework compatibility

This decision consolidates retained implementation evidence. It does not record a new compatibility run. The final integration owner must verify the locked stack at the newly frozen product revision.

A uses assistant-ui's compiler-owned native `present` toolkit and recursive tree renderer. B uses the real OpenUI parser/renderer in the repository-owned `compose_reactive_scene` Tool UI. Both use the shared assistant-ui chat shell, compact request-time snapshot, browser fare bridge, query worker, catalog and signed-in Codex provider. Stock `present_openui` is a final display, so it is not the continuation mechanism selected for B.

The integration package tree pins `@assistant-ui/react` 0.15.23, `@assistant-ui/ai-sdk` 0.0.9, `@assistant-ui/vite` 0.0.19, `@assistant-ui/react-generative-ui` 0.0.22, `ai` 7.0.127, `@ai-sdk/react` 4.0.130, `@openuidev/react-lang` 0.3.0, `@openuidev/lang-core` 0.3.0 and Zod 4.6.5. React's declared range is `^19.2.0`; the frozen run environment records actual installed versions rather than assuming every historical spike used this exact tree.
